# PrintLab — сайт мастерской 3D-печати

В папке есть два самостоятельных варианта одного сайта:

- `website-springboot` — Spring Boot + Java 17, Maven.
- `website-flask` — Flask + Python 3.9+.

Оба варианта показывают адаптивную страницу мастерской и считают ориентировочную цену печати на сервере. Расчёт учитывает материал, вес детали и скидку за количество. Модель для расчёта: 5 ₾ за подготовку + цена пластика за грамм; минимальная стоимость одной детали — 8 ₾; скидка 10% от 3 штук и 20% от 10.

## Запустить Flask

Откройте терминал в папке `website-flask` и выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Откройте <http://127.0.0.1:5000>.

## Запустить Spring Boot

Нужны JDK 17+ и Maven 3.6.3+. Откройте терминал в папке `website-springboot` и выполните:

```powershell
mvn spring-boot:run
```

Откройте <http://localhost:8080>.

В калькуляторе примерная цена показывается в грузинских лари (₾). Перед использованием для реальных заказов замените демонстрационные тарифы на свои.
